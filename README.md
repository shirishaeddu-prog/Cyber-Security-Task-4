Firewall Rule Simulation

Task 4: Setup and Use a Firewall

Objective
To understand basic firewall rules and how firewalls allow or block network traffic.

Description
This Python program simulates a simple firewall. It allows users to add rules, block specific ports, allow ports, and test whether a port is allowed or blocked.

 Features
- Add firewall rules
- Block port 23 (Telnet)
- Allow port 22 (SSH)
- Test port status
- Display current firewall rules

Tools Used
- Python
- Pydroid 3

 Sample Rules
- Port 23 → BLOCK
- Port 22 → ALLOW

 How to Run
1. Open Pydroid 3.
2. Create a new Python file.
3. Paste the Python code.
4. Click Run.
5. Check the output.

 Result
The program successfully demonstrates basic firewall traffic filtering by allowing or blocking ports according to the configured rules.

Note
This project is a simulation of firewall rules for learning purposes. It does not modify the actual Windows or Linux firewall.
